# HXD1C 发车作业虚拟实训

本仓库仅用于发布 HXD1C 电力机车发车作业网页实训，与出勤作业、手账填写及机车检查项目分开存放。

GitHub Pages 入口：

https://tanhaoyu646-bit.github.io/hxd1c-departure-operation/

当前发布内容包括：

- HXD1C 原版驾驶台图像与交互热区
- 大闸、小闸、方向手柄和牵引手柄操作
- 发车作业步骤引导与基础运行逻辑
- 内江至内江南约 12.6 km 的线路场景
- 桌面端与手机端页面适配

本轮增加：

- 教学模式下可在本机切换绿、绿黄、黄、红出站信号；考评模式随机绿、绿黄、黄。
- 点击出站信号机圆形放大确认；可按场景要求确认发车手信号视频。
- LKJ2000实体按键输入固定课堂训练参数，并逐条核对运行揭示。
- 简略制动机减压/缓解确认、过程评分和考评成绩单。
